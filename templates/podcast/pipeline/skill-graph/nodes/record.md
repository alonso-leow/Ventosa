# Node skill: record [human, teleprompter app]
The host records each script line (or segment) on the mic with the teleprompter: space marks take start/end, K/D = good/bad. Copy recorder files to the inbox (assets/camera/inbox/ or the folder set in Import), then 📥 Import: auto-match by marks or recording order; Keep → assets/camera/<line>-t<n>.<ext>, Discard → retake.
Events: record.recorded|discarded|reshoot|parked|dropped. The AI only reports progress.
