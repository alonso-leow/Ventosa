# My Channel

A Ventosa workspace (media template). The AI sees it as a skill graph; you see it as tasks and queues in Ventosa.

- `workspace.json` — brand, unit, platform, sponsor line, ports, rules.
- `pipeline/skill-graph/` — the steps and each node's skill. Edit freely.
- `tone.md`, `meta/`, `research/` — your knowledge. The AI reads these.
- Apps: `ventosa-labelling -w .`, `ventosa-teleprompter -w .`
- Graph CLI: `ventosa-graph -w . status`
