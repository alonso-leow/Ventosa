# Node skill: thesis (Label app ▸ Thesis) [human]
The human selects the thesis before any script is drafted. The AI wrote candidates (`options`); this is the human's call, not the AI's.

**Human does:** open the Label app ▸ Thesis tab, read each candidate's thesis and objectives, click the one to use (or write your own and add it as an option), then mark done. Only the chosen thesis gets a draft. To ask for another candidate use "one more option" instead.
Mark done: `ventosa-graph write human-done <ID> thesis` (choosing the thesis in the app also counts).
