# craft/

Reference knowledge the editing nodes read. Written for Ventosa in its own words; each file is one `K-*` entry in `steps.json`. They are guidance, not law: `tone.md`, the approved script and the graph's elevate rules win over anything here.

`K-motion` motion design · `K-explainer` structure and pacing · `K-ffmpeg` encoding recipes · `K-platforms` export specs · `K-captions` open captions · `K-animlib` motion tool choice and quality gates · `K-render` render backends (HyperFrames, Remotion) · `K-3d` 3D scenes · `K-genmedia` generated media · `K-browser` reference browsing.
